Beacon AI

Trend intelligence for macro, mega, and sub-trend research. This Netlify deployment serves a static public landing page. The interactive Streamlit workspace is run locally from the repository.

Run locally

Start the interactive app with streamlit run india-trend-radar/streamlit_app.py.

What Netlify serves

Netlify publishes the contents of the public directory, so the homepage here is a simple static entry point.

If you want Netlify to show something else, we can swap this page for a different static landing page or route structure.
